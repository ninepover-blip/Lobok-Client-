# Как вернуть исходники Lobok Client себе на компьютер

**Проблема:** проект живёт только на Vercel. Локальной папки нет — поэтому opencode
«не показывает файлы»: ему просто нечего показывать. Кнопки «скачать ZIP» у Vercel
нет ([официально подтверждено поддержкой](https://community.vercel.com/t/recovering-source-code-from-vercel-deployment/7379)),
но всё вытаскивается через их API.

Твои данные из ссылки:

| Что | Значение |
|---|---|
| Команда (scope) | `123-70f4` |
| Проект | `lobok-client` |
| Деплой | `2G1XCQUCBH8xje1V2CPYJTPtD3s4` |
| Сайт | https://lobok-client.vercel.app |

---

## Сначала проверь короткий путь (30 секунд)

Открой **Vercel → проект `lobok-client` → Settings → Git**.

- **Есть подключённый репозиторий?** Тогда ничего скачивать не надо:
  ```bash
  git clone https://github.com/ТВОЙ_ЮЗЕР/lobok-client.git
  cd lobok-client
  npm install
  opencode
  ```
- **Пусто / "No Git repository connected"?** → иди в шаг 1 ниже.

---

## Шаг 1. Создай токен Vercel

1. Открой https://vercel.com/account/settings/tokens
2. **Create Token**
3. Имя — любое, например `source-pull`
4. **Scope — обязательно выбери свою команду `123-70f4`**, не «Personal Account».
   Если промахнёшься со scope — API вернёт `403 Not authorized`.
5. Expiration — можно 1 день, больше не понадобится.
6. Скопируй токен (он показывается один раз).

---

## Шаг 2. Скачай исходники

Положи файл `pull-vercel-source.mjs` в любую папку, открой там терминал.
Нужен Node.js 18+ (проверь: `node --version`).

### Windows (PowerShell)
```powershell
$env:VERCEL_TOKEN="сюда_токен"
node pull-vercel-source.mjs 2G1XCQUCBH8xje1V2CPYJTPtD3s4 lobok-client --team=123-70f4
```

### Windows (CMD)
```cmd
set VERCEL_TOKEN=сюда_токен
node pull-vercel-source.mjs 2G1XCQUCBH8xje1V2CPYJTPtD3s4 lobok-client --team=123-70f4
```

### macOS / Linux
```bash
export VERCEL_TOKEN=сюда_токен
node pull-vercel-source.mjs 2G1XCQUCBH8xje1V2CPYJTPtD3s4 lobok-client --team=123-70f4
```

Сначала можно просто посмотреть, что там есть, ничего не качая:
```bash
node pull-vercel-source.mjs 2G1XCQUCBH8xje1V2CPYJTPtD3s4 --team=123-70f4 --list
```

В списке ты должен увидеть `app/stats/page.tsx` — ту самую страницу статистики.

## Шаг 3. Запусти проект локально и открой в opencode

```bash
cd lobok-client
npm install
git init && git add -A && git commit -m "recovered from vercel"
npm run dev          # http://localhost:3000
```

В **новом** окне терминала, **обязательно из этой же папки**:
```bash
cd путь/к/lobok-client
opencode
```

Проверить, что opencode смотрит куда надо, можно так:
```bash
opencode -c /полный/путь/к/lobok-client
```

> Если opencode упорно открывает старый/чужой проект — это известный баг с кэшем.
> Лечится удалением `~/.local/share/opencode/` (на Windows —
> `C:\Users\ТЫ\.local\share\opencode\`) и повторным запуском.

## Шаг 4. Сразу залей на GitHub, чтобы больше не терять

```bash
gh repo create lobok-client --private --source=. --push
```
или вручную: создай пустой репозиторий на github.com и

```bash
git remote add origin https://github.com/ТВОЙ_ЮЗЕР/lobok-client.git
git branch -M main
git push -u origin main
```

Потом в Vercel: **Settings → Git → Connect Repository**. После этого каждый
`git push` = автодеплой, и исходники всегда у тебя.

## Если что-то пошло не так

| Ошибка | Причина и лечение |
|---|---|
| `403 forbidden / invalidToken` | Токен создан не в том scope. Пересоздай, выбрав команду `123-70f4`. |
| `404 File tree not found` | У этого деплоя нет дерева исходников. Открой в дашборде **другой, более старый деплой** (Deployments → любой со вкладкой Source) и подставь его ID. |
| Файлы скачались с лишней папкой `src/` внутри | Так и должно быть срезано автоматически; если нужно наоборот сохранить — добавь `--keep-root`. |
| `fetch is not defined` | Старый Node. Нужен 18+, лучше 20+. |
