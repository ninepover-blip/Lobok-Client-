## Как забрать себе на компьютер

Скачай папку `lobok-client` из воркспейса, потом:

```bash
cd lobok-client
npm install --legacy-peer-deps
npm run dev            # http://localhost:3000
opencode               # теперь он видит файлы
```

> `.env` уже внутри и заполнен (Neon + Telegram + админы). В git он **не**
> закоммичен — так и надо.

## Важно: смени секреты

В `.env` лежат боевые доступы, а сессия opencode **публичная** — их видит любой,
у кого есть ссылка. Обязательно поменяй:

1. **Пароль базы Neon** — Neon Console → Roles → Reset password
2. **Токен Telegram-бота** — `@BotFather` → `/revoke`
3. **Пароли админов** `LayF` / `Vybe` — они лежат прямо в `.env` и в тексте сессии
4. `JWT_SECRET` и `NEXTAUTH_SECRET` — сейчас это заглушки вида `...change-in-production`

После смены обнови переменные в Vercel: **Project → Settings → Environment Variables**.
И удали публичный шаринг сессии, если он больше не нужен.

## Залей на GitHub, чтобы больше не терять

```bash
gh repo create lobok-client --private --source=. --push
```

Потом в Vercel: **Settings → Git → Connect Repository**. Дальше каждый `git push`
= автодеплой, и исходники всегда у тебя.
